# Proof-Jev roadmap

Version 0.5 focuses on source code: Git diffs, affected-test analysis, mutation execution, and optional Jev review. Browser workflows are excluded from the product.

## Shipped

- Six code-only MCP tools and three plugin skills.
- Diff-aware JavaScript/TypeScript mutation candidates with exact source patches.
- Disposable snapshots, repeated baselines and detected mutations, and explicit incomplete evidence.
- Structured Jev review with source locations, persistent budgets, and uncertainty.
- Offline HTML and machine-readable evidence reports.

## Next improvements

- Runtime coverage to distinguish unexecuted mutations from weak assertions.
- Framework/alias-aware test selection and wider language support.
- Requirement-grounded regression-test suggestions.
- Cross-file semantic analysis beyond import reachability.
- Evaluation on representative real changes before making accuracy or calibration claims.
